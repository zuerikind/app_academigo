**lib/utils/slots.ts:**
Export `LESSON_DURATION_MINUTES = 50`, `SLOT_INCREMENT_MINUTES = 15`, and `generateSlots` pure function.

Algorithm:
1. Check if targetDate (as YYYY-MM-DD string) appears in `blockedDates` array — return [] if so.
2. For each range: parse start_time/end_time as HH:MM, create Date objects anchored to targetDate (treat times as Europe/Zurich but for v1 use local date construction — combine date with time string). Walk from start to end in SLOT_INCREMENT_MINUTES steps, adding candidates where `candidate + LESSON_DURATION_MINUTES ≤ end`.
3. Filter candidates: exclude any where the candidate window overlaps with a booked slot (candidate < bookedEnd && candidateEnd > bookedStart).
4. Return candidates mapped to `.toISOString()`.

Important: construct slot times using `new Date(`${dateStr}T${time}:00`)` — this uses local time parsing which is acceptable for v1 (Zurich-only platform per CONTEXT.md).

**lib/queries/availability.ts:**
- `getTeacherAvailabilityRanges(teacherId)`: query `teacher_availability_ranges` where teacher_id = teacherId, return sorted by day_of_week, start_time.
- `getTeacherAvailabilityBlockers(teacherId)`: query `teacher_availability_blockers` where teacher_id = teacherId.
- `getAvailableSlotsForDay(teacherId, targetDate)`: parallel-fetch ranges for `targetDate.getDay()`, all blockers for teacher, confirmed/pending bookings for that day's TIMESTAMPTZ range. Call `generateSlots`. Return result.
- `getAvailableDaysForMonth(teacherId, year, month)`: iterate each day of the given month, call `getAvailableSlotsForDay` for days that match a day_of_week that has a range (optimization: first fetch ranges, then only check days whose dow has a range). Return array of day-of-month numbers with slots > 0.

**lib/actions/availability.ts:**
All four actions: `"use server"`, call `requireRole("teacher")`, validate inputs with zod (startTime pattern `^([01]\d|2[0-3]):[0-5]\d$`), upsert/delete via Supabase, call `revalidatePath("/", "layout")`, return `{}` on success or `{ error }` on failure.
