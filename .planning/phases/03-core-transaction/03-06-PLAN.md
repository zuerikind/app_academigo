**lib/actions/bookings.ts:**
Create `"use server"` file. All six actions per signatures above.

`requestBooking`:
- `requireRole("student")` — get profile
- Query `students` table to get student.id by profile.id
- Parse `teacherId`, `slotStart`, `topicNote` from formData
- Compute `slotEnd = new Date(new Date(slotStart).getTime() + LESSON_DURATION_MINUTES * 60_000).toISOString()`
- Call `supabase.rpc("create_booking", { p_student_id, p_teacher_id, p_start_time, p_end_time, p_topic_note })`
- Handle error: if error.message includes "insufficient_credits" return `{ error: "You don't have enough credits for this booking." }`
- On success: `revalidatePath("/", "layout")` and return `{}`

`confirmBooking`:
- `requireRole("teacher")` — get profile → teacher record with `default_meet_link`
- Parse `bookingId`, `meetLink` (override, may be empty) from formData
- `const finalLink = meetLink.trim() || teacher.default_meet_link || null`
- Update: `bookings SET status='confirmed', meeting_link=finalLink WHERE id=bookingId AND teacher_id=teacher.id AND status='pending'`
- If no rows updated: return `{ error: "Booking not found or already actioned." }`
- Fetch booking + student profiles for email
- Call `sendBookingConfirmation(...)` in try/catch (non-blocking)
- `revalidatePath("/", "layout")` and return `{}`

`declineBooking`:
- `requireRole("teacher")`
- Parse `bookingId`, `alternativeSlot` (optional) from formData
- Call `supabase.rpc("cancel_booking", { p_booking_id: bookingId })` — this returns credits
- If `alternativeSlot` provided: update booking record with `alternative_slot_offered = alternativeSlot` if column exists, else skip
- `revalidatePath("/", "layout")`

`markComplete`:
- `requireRole("teacher")`
- Parse `bookingId` from formData
- Call `supabase.rpc("complete_booking", { p_booking_id: bookingId })`
- Handle error (booking not found, already completed)
- `revalidatePath("/", "layout")`

`cancelBooking`:
- Accept either role (student or teacher)
- Parse `bookingId` from formData
- Verify the caller is student_id or teacher_id on the booking
- Call `supabase.rpc("cancel_booking", { p_booking_id: bookingId })`
- `revalidatePath("/", "layout")`

`updateBookingMeetLink`:
- `requireRole("teacher")`
- Parse `bookingId`, `meetLink` from formData
- Validate meetLink starts with "https://"
- Fetch current `booking.meeting_link` first
- `const hadLink = booking.meeting_link !== null`
- Update `bookings SET meeting_link=meetLink WHERE id=bookingId AND teacher_id=teacher.id AND status='confirmed'`
- If `!hadLink`: fetch student email → call `sendMeetLinkAdded(...)` in try/catch
- `revalidatePath("/", "layout")`

**lib/queries/bookings.ts:**
Implement per shapes above. For joins: `teachers ( id, default_meet_link, profiles ( full_name, avatar_url ) )` and `students ( id, profiles ( full_name, avatar_url ) )`. Include `reviews ( id, rating, comment )` in student bookings query. Order by `start_time DESC` for history, `start_time ASC` for upcoming.
