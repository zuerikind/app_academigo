Use a custom TSX monthly calendar grid — no new dependency needed. The grid is ~50 lines: compute days in month, render as 7-col grid, highlight days that have at least one slot. No date-fns needed for this.

**Slot fetching approach:** The calendar is a Client Component (needs interactivity for day selection). Slot fetching for a specific day must happen client-side after day click. Options:

Use a Server Action approach: create `getAvailableSlotsAction(teacherId, dateStr)` in lib/actions/availability.ts (a Server Action that wraps getAvailableSlotsForDay and returns the slot array). This avoids a new API route and stays consistent with the project's Server Action pattern.

First, extend lib/actions/availability.ts with a new Server Action (add to existing file):
```typescript
export async function getAvailableSlotsAction(
  teacherId: string,
  dateStr: string // YYYY-MM-DD
): Promise<string[]> {
  "use server";
  const date = new Date(dateStr + "T00:00:00"); // treat as local midnight
  return getAvailableSlotsForDay(teacherId, date);
}
```

Also add `getAvailableDaysInMonth(teacherId, year, month)` query to lib/queries/availability.ts:
- Fetches all teacher_availability_ranges for the teacher
- Returns a Set<number> of day_of_week values that have ranges
- Also fetches teacher_availability_blockers for the month to subtract blocked dates
- Returns an array of date strings (YYYY-MM-DD) that have availability
