**Card sections by status:**

**PENDING bookings:**
- Student name, date/time, topic note
- "Confirm" expandable form section:
  - `<input type="url" name="meetLink" defaultValue={teacherDefaultMeetLink ?? ""}>`
  - If `teacherDefaultMeetLink` is null: show warning banner "No default Meet link set — you must enter one before confirming. You can save a default link in Settings."
  - `<button type="submit">Confirm booking</button>`
  - Server Action: `confirmBooking` via `useActionState`
- "Decline" form: simple form with hidden bookingId, optional alternative slot picker (date + time selects), submit button
- Display `state.error` if action returned error

**CONFIRMED (upcoming) bookings:**
- Student name, date/time, topic note, credits_reserved
- **Meet Link Status indicator:**
  - If `booking.meeting_link !== null`: green Badge "Meet Link Added" + display the link (truncated) + "Update" inline form
  - If `booking.meeting_link === null`: orange Badge "Meet Link Missing" + inline input to add link (`updateBookingMeetLink` action)
- "Mark Complete" button: form with hidden bookingId — only show if `new Date(booking.start_time) < new Date()` (session is in the past)
- "Cancel" button: form with hidden bookingId → `cancelBooking`
- Calendar download link: `<a href={/api/bookings/${booking.id}/ics}>Download .ics</a>`

**COMPLETED bookings:**
- Student name, date/time, amount earned
- Status Badge "Completed" (green)
- No action buttons

**CANCELLED bookings:**
- Student name, date/time
- Status Badge "Cancelled" (muted)

Use existing `Card`, `CardHeader`, `Badge`, `StatusBadge` components from `components/ui`. Use `lucide-react` `CheckCircle`, `AlertCircle`, `Link2` icons for Meet Link Status. Each form uses `useActionState` + `useFormStatus` for loading state on submit buttons.
