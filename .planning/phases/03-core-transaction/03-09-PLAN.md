**components/student/review-form.tsx** (`"use client"`):

Props:
```typescript
interface ReviewFormProps {
  bookingId: string;
  hasReview: boolean;  // if true, already reviewed — show "Review submitted" instead
}
```

State: `open: boolean`, `rating: number` (0 = unset), bound to `useActionState(submitReview.bind(null, bookingId), {})`.

Logic:
- If `hasReview || state.success`: render `<p className="text-sm text-muted">Review submitted. Thank you!</p>` only.
- If `!open`: render `<button onClick={() => setOpen(true)}>Leave a review</button>`.
- If `open`: render inline form:
  ```tsx
  <form action={action}>
    <input type="hidden" name="rating" value={rating} />
    <div role="group" aria-label="Rating">
      {[1,2,3,4,5].map(n => (
        <button key={n} type="button" onClick={() => setRating(n)}
          className={n <= rating ? "text-yellow-500" : "text-muted-foreground"}>
          <Star size={20} fill={n <= rating ? "currentColor" : "none"} />
        </button>
      ))}
    </div>
    <textarea name="comment" placeholder="Optional comment..." rows={3} className="w-full..." />
    {state.error && <p className="text-destructive text-sm">{state.error}</p>}
    <SubmitButton label="Submit review" />
  </form>
  ```

Note: `submitReview.bind(null, bookingId)` follows the Phase 2 pattern for bound actions with `useActionState` — the action signature is `(bookingId, prev, formData)`.
