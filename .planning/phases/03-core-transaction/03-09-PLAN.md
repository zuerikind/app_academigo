Create lib/queries/earnings.ts:

`getTeacherEarnings(teacherId)`:
```typescript
// select teacher_earnings joined to bookings → students → profiles
// fields: id, amount, created_at, booking_id, studentName
from teacher_earnings
join bookings on teacher_earnings.booking_id = bookings.id
join students on bookings.student_id = students.id
join profiles on students.profile_id = profiles.id
where teacher_earnings.teacher_id = teacherId
order by teacher_earnings.created_at DESC
```
Handle Supabase nested join type inference with explicit casts as needed.

`getTeacherPayoutRequests(teacherId)`:
```typescript
select id, amount, status, payout_info, requested_at, processed_at, reference_note
from payout_requests
where teacher_id = teacherId
order by requested_at DESC
```

`getPendingBalance(teacherId)`:
```typescript
// total earnings - sum of processed payout amounts
const { data: earnings } = await supabase.from('teacher_earnings').select('amount').eq('teacher_id', teacherId)
const { data: payouts } = await supabase.from('payout_requests').select('amount').eq('teacher_id', teacherId).eq('status', 'processed')
const totalEarned = earnings?.reduce((s, e) => s + e.amount, 0) ?? 0
const totalPaidOut = payouts?.reduce((s, p) => s + p.amount, 0) ?? 0
return Math.max(0, totalEarned - totalPaidOut)
```

Create lib/actions/earnings.ts with `"use server"`:

`requestPayout(_prev: { error?: string; success?: boolean }, formData: FormData)`:
- requireRole("teacher")
- Get teacher record by profile_id
- payoutInfo = String(formData.get("payoutInfo") ?? "").trim()
- pendingBalance = await getPendingBalance(teacher.id)
- Return { error: "No pending balance to request payout for." } if pendingBalance <= 0
- Check for existing pending payout: query payout_requests where teacher_id = teacher.id AND status = 'pending'; return { error: "A payout request is already pending." } if found
- Insert into payout_requests: { teacher_id: teacher.id, amount: pendingBalance, payout_info: payoutInfo, status: 'pending', requested_at: new Date().toISOString() }
- revalidatePath("/", "layout")
- Return { success: true }
