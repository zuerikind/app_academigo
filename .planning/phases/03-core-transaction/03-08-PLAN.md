Create lib/actions/reviews.ts with `"use server"`:

`submitReview(bookingId: string, _prev: { error?: string; success?: boolean }, formData: FormData)`:
- requireRole("student") to get profile and student record
- Extract rating (parseInt), comment (trim, optional) from formData
- Return { error: "Rating must be between 1 and 5." } if rating < 1 or > 5
- Verify booking exists, status = 'completed', and student_id matches the current student
- Insert into reviews: { booking_id: bookingId, student_id: student.id, rating, comment: comment || null }
- Handle unique constraint error (Postgres code 23505): return { error: "You have already reviewed this session." }
- revalidatePath("/", "layout")
- Return { success: true }

Create lib/queries/reviews.ts:

`getTeacherReviews(teacherId)`:
- Select from reviews joined to students → profiles (for student name)
- Filter by teacher_id = teacherId (join through bookings: reviews → bookings where teacher_id = teacherId)
- OR: add teacher_id to reviews in the query via: `from reviews join bookings on reviews.booking_id = bookings.id where bookings.teacher_id = teacherId`
- Return array of { id, rating, comment, createdAt, studentName }

`getReviewAggregate(teacherId)`:
- Query the above to compute average rating and count
- Can be done client-side from the reviews array or as a DB aggregate
- Return `{ avgRating: number; count: number }`
