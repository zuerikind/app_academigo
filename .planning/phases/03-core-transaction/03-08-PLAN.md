**REV-04: Update teacher directory to show avg rating + review count**

Read `lib/queries/admin.ts` (or whichever file exports `getApprovedTeachers` — search if unsure). Extend the query to include review aggregate data.

Add to the `getApprovedTeachers` select or compute post-fetch:
- `avg_rating: number | null` — average star rating (null when no reviews)
- `review_count: number` — total review count (0 when no reviews)

Implementation approach: After fetching teachers, run a single supplementary query to get review aggregates per teacher, then merge:

```typescript
// Fetch all approved teachers (existing)
const { data: teachers } = await supabase
  .from("teachers")
  .select("id, teacher_level, profiles ( full_name, avatar_url ), ...")
  .eq("is_approved", true);

// Fetch review aggregates per teacher
const { data: reviewAggregates } = await supabase
  .from("reviews")
  .select("teacher_id")
  .in("teacher_id", teachers.map(t => t.id));

// Compute per teacher
const ratingMap = new Map<string, { sum: number; count: number }>();
for (const r of reviewAggregates ?? []) {
  // NOTE: reviews table also has rating — extend select to include rating
  const entry = ratingMap.get(r.teacher_id) ?? { sum: 0, count: 0 };
  entry.sum += r.rating;
  entry.count++;
  ratingMap.set(r.teacher_id, entry);
}

return teachers.map(t => ({
  ...t,
  avg_rating: ratingMap.has(t.id) ? ratingMap.get(t.id)!.sum / ratingMap.get(t.id)!.count : null,
  review_count: ratingMap.get(t.id)?.count ?? 0,
}));
```

Make sure the reviews select includes `rating` and `teacher_id`.
