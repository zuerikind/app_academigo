  <action>
Run `npm install stripe@^17` to install the Stripe SDK.

Create lib/actions/payments.ts following RESEARCH.md Pattern 3 exactly:
- `"use server"` directive
- Instantiate Stripe with `process.env.STRIPE_SECRET_KEY!` and `apiVersion: "2025-10-28"`
- Export `createCheckoutSession(_prev: { error?: string }, formData: FormData)`
- Read `packageSlug` from formData
- Get locale from getActionLocale() (from lib/actions/locale.ts)
- requireRole("student", locale) — redirect to login if unauthenticated
- Query `credit_packages` where slug = packageSlug AND is_active = true
- Return `{ error: "Package not found." }` if not found or no stripe_price_id
- Query `students` by profile_id
- Construct success_url: `${process.env.NEXT_PUBLIC_SITE_URL}${localizedPath(locale, "/student/packages")}?success=true&session_id={CHECKOUT_SESSION_ID}`
- Construct cancel_url: same path + `?cancelled=true`
- Create checkout session with mode: `pkg.is_subscription ? "subscription" : "payment"`
- Include metadata: `{ student_id, package_id, package_slug }`
- If no session.url: return `{ error: "Checkout session creation failed." }`
- Call `redirect(session.url)` — this throws; do NOT wrap in try/catch

Create app/api/webhooks/stripe/route.ts following RESEARCH.md Pattern 4:
- Export `async function POST(request: Request)`
- `const body = await request.text()` — FIRST operation, before anything else
- `const headersList = await headers()` from next/headers
- Get `stripe-signature` header; return 400 if missing
- `stripe.webhooks.constructEvent(body, sig, process.env.STRIPE_WEBHOOK_SECRET!)`
- Catch and return 400 with "Webhook signature verification failed"
- Handle `checkout.session.completed`: call `handleCheckoutComplete(session)` — implements idempotency check + grant_credits for one-off, skip for subscription (subscription first payment also comes via invoice.paid)
- Handle `invoice.paid`: call `handleInvoicePaid(invoice)` — for subscription renewals, call `grant_subscription_credits` RPC (RESET semantics)
- Return `new Response(JSON.stringify({ received: true }), { status: 200 })`

`handleCheckoutComplete`:
1. Check payments table for existing row with stripe_session_id + status='completed' — return if found (idempotency)
2. Look up package credits from credit_packages by package_id from session.metadata
3. Upsert payments row with onConflict: 'stripe_session_id'
4. If `session.mode === 'payment'`: call `supabase.rpc('grant_credits', { p_student_id, p_credits })`
5. (subscription mode: skip — invoice.paid handles it)

`handleInvoicePaid`:
1. Get subscription object from invoice; get package_id from metadata
2. Check for existing invoice payment in payments table (idempotency on invoice.id)
3. Call `supabase.rpc('grant_subscription_credits', { p_student_id, p_credits })` — RESET semantics
4. Record invoice.id in payments table to prevent duplicate grants

Run tests: `npm test -- --testPathPattern="actions/payments|api/webhooks" --passWithNoTests`
