**Step 3 — lib/actions/payments.ts:**
Create `"use server"` file. Import `Stripe` from `"stripe"` (server-only). Use API version `"2025-10-28"` (verify this is valid on install — if SDK throws on this version use the SDK's default by omitting apiVersion). 

Implement `createCheckoutSession` exactly per RESEARCH.md Pattern 3:
- `requireRole("student")` auth guard
- Query `credit_packages` for the packageSlug — return error if not found or no `stripe_price_id`
- Query `students` table to get student.id by profile.id
- Create Stripe checkout session with `mode: "subscription"` for `is_subscription=true`, else `"payment"`
- `success_url`: `${NEXT_PUBLIC_SITE_URL}${localizedPath(locale, "/student/packages")}?success=true&session_id={CHECKOUT_SESSION_ID}`
- `cancel_url`: `${NEXT_PUBLIC_SITE_URL}${localizedPath(locale, "/student/packages")}?cancelled=true`
- `metadata`: `{ student_id, package_id, package_slug }`
- Call `redirect(session.url)` on success

**Step 4 — app/api/webhooks/stripe/route.ts:**
Create Route Handler outside `[locale]` prefix (correct per RESEARCH.md Pitfall 5).

`POST` handler:
1. `const body = await request.text()` — FIRST LINE, no exceptions
2. `const headersList = await headers()` then `const sig = headersList.get("stripe-signature")`
3. Return `new Response("Missing signature", { status: 400 })` if no sig
4. `stripe.webhooks.constructEvent(body, sig, process.env.STRIPE_WEBHOOK_SECRET!)` — return 400 on error
5. Handle `checkout.session.completed`:
   - Extract `metadata.student_id`, `metadata.package_id` from session
   - Check `payments` table for existing `stripe_session_id` — if found, return 200 (idempotent)
   - Look up package `credits` and `is_subscription` from `credit_packages`
   - Insert into `payments` table: `{ student_id, stripe_session_id, package_id, amount_chf }`
   - Call `grant_credits` RPC for one-off; `grant_subscription_credits` for subscriptions
6. Handle `invoice.paid`:
   - Get `subscription` ID from invoice, look up customer → student via metadata or customer lookup
   - Check idempotency via `invoice.id` stored in payments
   - Call `grant_subscription_credits` RPC
7. Return `Response.json({ received: true }, { status: 200 })`

**Step 5 — next.config.ts:**
Read the file. If `serverExternalPackages` is not already present, add `serverExternalPackages: ["stripe"]`. Only needed if build errors appear — add defensively now.
